## The line

> My fridge's ice maker sounds like a robot giving up on life, and the light still flicks on at 3 a.m. just to watch me eat standing up like a raccoon.

One line, roasting the fridge on one concrete, recognisable detail — the ice maker groaning like a dying robot — with the twist landing in the last words: the fridge light as a silent witness to a 3 a.m. snack, eaten standing up like a raccoon.
